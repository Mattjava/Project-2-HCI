# Catch Track

## A fisherman's best way to track their catches

- Build a collection of the fish you caught
- Learn about your performance
- Discover various species that you caught
- Contribute to population sampling

## Tech Stack

- Python
  - Streamlit (UI)


## Set-up

1. Create virtual environment (python -m venv venv)
2. Activate environment ((WIN) venv/Scripts/activate | (MAC/LINUX) source venv/bin/activate)
3. Install dependencies (pip install -r requirements.txt)
4. Run program (streamlit run main.py)
